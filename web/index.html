RepoPilot

Repository readiness checks. Scan a public GitHub repository, or look at the synthetic samples further down.

Scan a public GitHub repository

Your browser contacts GitHub directly (api.github.com and raw.githubusercontent.com), read-only and without a token. Nothing is sent to any other server. GitHub allows 60 requests per hour per IP address; a scan uses 2. Results come from the repository's default branch at one commit, and every file name is shown as text.

Sample reports

Sample reports use synthetic data and make no network requests. In these sample reports the Evidence column shows the file names a check matched, as plain text; no link is made because no real repository is behind them.
