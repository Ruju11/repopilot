How the scan works

Your browser contacts GitHub directly (api.github.com and raw.githubusercontent.com), read-only and without a token. Nothing is sent to any other server. GitHub allows 60 API requests per hour per IP address, and a scan uses 2 API requests plus up to 5 README or licence downloads. Results come from the repository's default branch at one commit, and every file name is shown as text.

Limits

  • A passing README check means a README file exists. It says nothing about quality.
  • Licence detection is a keyword match on the licence text, not a legal check.
  • It does not read source code, find vulnerabilities, or support private repositories.
