Check a public repository for the basics

RepoPilot looks for a README, licence, security policy, CI configuration and other common project files, and shows which file each result is based on.

Scan a public GitHub repository

Your browser contacts GitHub directly (api.github.com and raw.githubusercontent.com), read-only and without a token. Nothing is sent to any other server. GitHub allows 60 requests per hour per IP address; a scan uses 2 or 3. Results come from the repository's default branch at one commit, and every file name is shown as text.

Enter owner/repo or a github.com URL. Press / to jump here.

What it checks, and what it does not

Limits

  • A passing README check means a README file exists. It says nothing about quality.
  • Licence detection is a keyword match on the licence text, not a legal check.
  • It does not read source code, find vulnerabilities, or support private repositories.
  • A project that keeps these files elsewhere will show a warning.
